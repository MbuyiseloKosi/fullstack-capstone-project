# GiftLink User Stories

## User Stories
1. As a user, I want to register so I can post items.
2. As a user, I want to log in so I can manage my profile.
3. As a user, I want to view all items so I can browse available gifts.
4. As a user, I want to search items by category so I find what I need.
5. As a user, I want to view item details so I can see the condition and location.
6. As a user, I want to comment on an item so I can ask questions.
7. As a user, I want to edit my profile so I can update my contact info.
8. As a user, I want to delete my account so I can remove my data.
